# 中国当代文学史 · 数字长卷（1949—2018）

以水墨长卷形式呈现中国当代文学史的可视化网页：时间轴 · Wiki · 双链图谱 · 地图，四种视图共享同一份从 Obsidian 知识库（`D:\Doc\Vault\MARKING\中国文学史`）构建的数据。

## 快速开始

- **日常使用**：双击 `启动网页.bat`（自动重建数据 → 打开 http://localhost:8080）
- **只想重建数据**：双击 `重建数据.bat`（或命令行 `node tools/build-data.mjs`）
- 知识库内容有更新后，重跑一次即可同步到网页

## 四个视图

| 视图 | 内容 | 操作 |
|------|------|------|
| **时间轴** | 长卷=固定宽度的"超宽网页"：时期题字 → 主要事件卡 → 次要事件 → 人物印章 → 群体/流派带，所有卡片尺寸与位置固定不变 | **左右拖动**浏览（可上下拖）；**滚轮=屏幕放大镜**（锚定光标）；放大超过 1.7 倍自动聚焦视口中心的事件（朱砂虚线环+抽屉展开详情），缩小回退出聚焦并收起抽屉；底部缩略条可点击跳转 |
| **Wiki** | 773 张知识卡 + 50 篇分期笔记/综述，双链可点击跳转 | 左侧分类树、正文双链、卡片底部跨视图按钮 |
| **图谱** | 全部实体与 2500+ 条双链的力导向图 | 悬停高亮邻居、类型筛选、拖动节点、双击空白回位 |
| **地图** | 人物/群体/刊物的地图钉（含经纬度与活动年份） | 拖动年份滑杆看"谁在哪里"，▶ 播放，点钉开详情 |

顶栏搜索（Ctrl+K）可全库检索人物/事件/思潮/笔记；详情抽屉里可"在 Obsidian 中打开"原笔记。

## 编年口径：两部文学史的切换与比对

顶栏「朱栋霖 / 洪子诚 / 比对」切换编年口径（快捷键 `S` 循环，深链 `#/timeline?src=hong`）：

- **朱栋霖**（默认）：《中国现代文学史 1915—2018》书末大事记，提要式，1949—2018
- **洪子诚**：《中国当代文学史》书后年表，逐月详编，1949—2000
- **比对**：双轨并置——轴上朱记事件卡、轴下洪表按月聚合的密度柱（柱高∝当月条数），里程碑为大号锚点；同一里程碑两书各命中一条时，抽屉「另一史对照」可直接互跳

词条卡不随口径拆分：卡片恒显示全部内容，正文下方并排**两史口径对照**块——每部教材各自提及几次、在哪些章节小节着重讲、原文摘段、以及人工评语（`curated.json` 的 `compare_notes`，可自行扩充）。

## 颜色语义

- **类型色**（圆点/卡片左边条）：事件=朱砂红 · 政策=紫棠 · 作品·刊物=驼金 · 人物=缃褐 · 思潮/群体=黛蓝（时间轴右上"图例"面板可对照，点击标题可折叠）
- **时期色**（底纹/群体带/时期题字）：十七年=赭 · 文革=玄灰 · 新时期=竹青 · 九十年代=黛蓝 · 新世纪=青莲
- **聚焦**：屏幕放大到阈值以上时，视口中心的事件自动成为焦点（虚线环），抽屉同步展示其策展说明、编年原文与关联条目

## 数据来源与策展层

- `wiki/` 870 张卡片（frontmatter + 双链）→ 实体与关系
- 两部教材编年并轨入库：朱栋霖《大事记》（1949—2018）+ 洪子诚书后年表（1949—2000），事件带 `src` 来源标记
- `tools/curated.json` → **人工策展层**，你可以直接编辑：
  - `milestones`：浓墨里程碑（年份 + 关键词匹配 + 说明；`match` 需全部包含、`matchAny` 命中任一即可，`month` 仅约束朱侧精确纪时）
  - `important_persons`：人物印章收录名单（按顺序即重要性）
  - `bands`：群体/流派时间带
  - `people_life`：人物生卒补齐
  - `locations`：地图钉（名称/城市/经纬度/活动年份/一句话）
  - `compare_notes`：两史口径人工评语（词条"两史口径对照"块里的 ✎ 评语）
  改完运行 `node tools/build-data.mjs` 生效。

## 换主题 / 换配色

- 全部颜色、字体、圆角、动效集中在 `css/theme.css` 的 CSS 变量（含暗色主题占位 `:root[data-theme="dark"]`）
- 分期定义、类型色、缩放显影阈值在 `js/config.js`
- 改这两个文件即可整体换肤，组件样式只引用变量

## 目录结构

```
index.html          入口（双击或经本地服务器访问）
css/theme.css       设计令牌（换肤改这里）
css/main.css        布局与组件
js/config.js        分期/类型/LOD 阈值
js/app.js           路由、详情抽屉、全局搜索
js/timeline.js      时间轴长卷
js/wiki.js          Wiki 视图
js/graph.js         双链图谱
js/map.js           地图视图
js/data.js          ← 由脚本生成，勿手改
lib/                d3 / echarts / marked / 中国GeoJSON / 霞鹜文楷（全部本地化，离线可用）
tools/build-data.mjs  数据管线（Node ≥18，零依赖）
tools/curated.json    人工策展层
tools/serve.mjs       零依赖静态服务器
```

## 备注

- 需要 Node.js（≥18）用于数据管线与本地服务器；网页本身零构建、零网络依赖
- 网页默认经 `http://localhost:8080` 访问；直接双击 index.html 也可用（数据以 script 注入，绕开 file:// 限制）
