# 动效升级计划书 · v2-framework 分支

> 2026-10-21 定稿。目标：把「中国当代文学史数字长卷」重构为 Vite + React 框架站，
> 动效达到主流大厂官网水准（弹簧物理、共享元素过渡、编排式入场、丰富微交互）。
> `main` 分支与线上部署不受影响；数据管线（`tools/build-data.mjs` → `js/data.js`）零改动。

## 一、架构决策

| 决策 | 内容 | 理由 |
|---|---|---|
| 分支隔离 | `v2-framework` 自 main 切出，新代码全部在 `v2/` 子目录 | 根目录静态版原样保留，可随时对照/回退 |
| 技术栈 | Vite 5 + React 18 + TypeScript + `motion`（framer-motion 新包名） | layoutId 共享元素 / AnimatePresence / spring / useReducedMotion 开箱即用 |
| 图表依赖 | d3、echarts、marked 走 npm，Vite 打包 | 保持全资源本地化、离线可用精神；echarts 仍动态 import 按需分块 |
| Islands 架构 | timeline/graph/map/puzzle 四个引擎（~3100 行手调 canvas/SVG）**逐字移植为命令式模块**，React 只在 `useEffect` 里挂载/卸载 | 控制回归风险；固定文档模型等钦定决策不动 |
| Wiki | 唯一完全 React 化的视图（纯 DOM，重写收益最大） | 目录树弹簧折叠、文章交叉过渡、滚动显影 |
| 数据层 | `import '../js/data.js'`（side-effect，window.DATA）；`data-body.js` 保持动态注入惰性语义 | 数据管线零改动 |
| 约束守护 | 时间轴固定文档模型不动；键盘事件集中分发；每色必有图例；`prefers-reduced-motion` 双层降级贯穿；开幕保持简洁两段式只做顺滑化 | 子级 AGENTS.md 硬性规则 |

## 二、动效规格（大厂水准的具体落点）

### Shell 全局层（React + motion）
1. **顶栏 Tab**：墨条指示器改 `layoutId` 共享元素，弹簧滑动 + 宽度形变；按钮 `whileHover` 墨色渐染、`whileTap` 按压回弹（scale .96 弹簧释放）。
2. **视图切换**：`AnimatePresence mode="wait"`——旧视图 0.15s 淡出下潜；新视图容器淡入上浮 + 图例/工具栏/侧栏/滑杆错峰显影；带 focus 等内容参数的深链跳过容器编排直接进内容动画。
3. **详情抽屉**：弹簧滑入（物理回弹可感知）+ 背景纸色 scrim 渐显（点击关闭）+ `drag="x"` 甩关 + 标题逐字显影 + 动作按钮 stagger。
4. **全局搜索 → 命令面板**：0.96→1 弹簧缩放入场、背景模糊 scrim、结果 18ms/条 stagger（仅结果集变化时重放）、↑↓ 键盘导航 + 高亮条 layoutId 滑动、Enter 直达。
5. **Toast**：弹簧浮入 + 细进度线 + 队列化逐条退场。
6. **帮助浮层**：卡片弹簧缩放 + 分组行 stagger。
7. **开幕卷轴（顺滑化，不加时长）**：物理感缓动、题字拉开前先行淡出、保留 `__curtainOpening` 时序契约、点击跳过。
8. **focus-visible** 全局统一朱砂 2px 外环。

### 五视图
- **时间轴**（island）：卡片光标邻近墨染高亮（rAF 节流，仅改 class）；聚焦虚线环呼吸旋转；`animateTo` 缓动升级；图例浮层 stagger。
- **Wiki**（React）：目录树高度弹簧折叠 + 条目 stagger；文章 AnimatePresence 交叉过渡（标题逐字 + 段落 stagger）；正文区块 useInView 一次性显影；顶部阅读进度墨线；目录 scrollspy 墨条。
- **图谱**（island）：节点按度数序渐显材质化；悬停光环呼吸（rAF 正弦）；邻居边虚线流动（dash offset）。
- **地图**（island）：钉入场 elasticOut 回弹；年份数字滚轮翻页（odometer）；播放钮 ▶/⏸ 形变 + 脉冲；图例滑杆首次入场编排。
- **拼图**（island）：卡片上板落地弹簧（scale 过冲 + 阴影收敛）；新连线 stroke-dashoffset 描线生长；卡片库分组展开 stagger。

### 性能红线
只动 transform/opacity/color；canvas 引擎状态不进 React；stagger ≤24 条；echarts 动态 import；时间轴每帧单 transform 不变。

## 三、实施阶段

- **阶段 0** ✅ 分支 + 本计划书。
- **阶段 1** 脚手架（网络关卡）：npm 源 `https://registry.npmmirror.cn` + 10 次重试环；`v2/` 建 Vite+React+TS 工程；装 motion/d3/echarts/marked；复制字体；接通 data.js。**兜底链**：npmmirror → npmjs → esm.sh vendored → 停下报告用户。
- **阶段 2** Shell：骨架 + 顶栏 + Tab 墨条 + 视图切换 + 抽屉 + 命令面板 + Toast + 帮助 + 卷轴 + hash 路由（深链协议 `#/view?key=val` 不变）。
- **阶段 3-6** 视图移植：Wiki → 时间轴 → 图谱 → 地图 → 拼图（独立文件夹 + 视图注册表接线，互不相交，可并行）。
- **阶段 7** 动效精修 + reduced-motion 审查。
- **阶段 8** 验收：`vite build && vite preview`，browser-accept 渲染走查（1440 桌面 + 375 窄屏；开幕→Tab→抽屉→Ctrl+K→Wiki 滚动→地图播放→拼图拖放；console 零报错；reduced-motion 直跳终态）；问题走修复循环。
- **阶段 9** `v2/README.md` + 最终提交。

## 四、执行方式

动态工作流（用户钦定）：阶段 1-2 串行奠基 → 阶段 3-6 四视图子代理并行 → 阶段 7-8 精修验收。每步 `npm run build` 门禁，验收不过触发修复子代理循环。结构性问题用 AmendWorkflow 修订。

## 五、风险与对策

- **npm 网络不稳**（本环境已知大坑）：npmmirror 优先 + 重试环 + esm.sh 回退 + 人工决策点。
- **移植回归**：引擎逐字搬运，React 只包生命周期；每岛 build 门禁。
- **包体**：motion ~18KB + React ~45KB gzip；echarts 按需分块；首屏与现状同量级。
- **敏感内容纪律**：纯 UI 层工作，不触碰 `js/data.js`/`js/data-body.js`/`tools/curated.json` 正文；不改 build-data.mjs；不 push。
